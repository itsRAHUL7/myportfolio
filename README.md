# 🚀 itsRAHUL7 Portfolio

A modern, high-performance personal portfolio built with **React 19** and **Express 5**. This project is optimized for both **Vercel** (Full Stack) and **GitHub Pages** (Frontend).

## 🌍 Live Links
- **Vercel Deployment**: [https://personal-portfolio-delta.vercel.app](https://personal-portfolio-delta.vercel.app) (Serverless API included)
- **GitHub Pages**: [https://itsRAHUL7.github.io/myportfolio/](https://itsRAHUL7.github.io/myportfolio/) (Frontend only)

## ✨ Technical Highlights
- **React 19 & React Router 7**: Utilizing the latest React features for efficient rendering.
- **Express 5 Serverless API**: A robust backend in the `/api` folder to handle Contact Form submissions.
- **Vercel Analytics**: Built-in monitoring to track visitor engagement.
- **Responsive Animations**: Smooth UI transitions using `Animate.css` and `react-on-screen`.
- **Dynamic Icons**: Integration with `react-bootstrap-icons`.

## 🛠️ Tech Stack
- **Frontend**: React 19, Bootstrap 5, React-Bootstrap
- **Backend**: Express 5, Nodemailer (Gmail integration)
- **Deployment**: Vercel & GitHub Pages
- **Analytics**: Vercel Analytics

## 🚀 Setup & Installation

### Local Development
```bash
# Install dependencies
npm install --legacy-peer-deps

# Start React app
npm start
```

### Deployment to GitHub Pages
```bash
npm run deploy
```

## 📬 Contact Form Configuration
To make the contact form functional on Vercel, set these environment variables:
- `EMAIL_USER`: Your Gmail address.
- `EMAIL_PASS`: Your Gmail App Password.
